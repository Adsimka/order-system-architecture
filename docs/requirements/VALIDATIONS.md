## Работа с диаграммами (PlantUML)

Диаграммы хранятся в формате "Diagram as Code" (`.puml`). Чтобы гарантировать их актуальность и корректность синтаксиса,   
в проекте настроен процесс валидации на всех этапах: локально, через скрипты автоматизации и в CI/CD.

### 1) Локальная проверка
Перед коммитом разработчик обязан убедиться, что диаграммы не содержат синтаксических ошибок.
- Рекомендуемый способ: Использовать плагин *PlantUML* в IDEA. Он подсвечивает ошибки в реальном времени и показывает превью.
- CLI способ: Если установлен Java, можно запустить проверку через Makefile (см. ниже) или прямой командой:
  ```bash
  java -jar tools/plantuml.jar -checkonly docs/diagrams/**/*.puml

### 2) CI-гейт в GitHub Actions

Чтобы случайно не тащить битые диаграммы в `main`, на каждый PR настроен автоматический чек (`.github/workflows/plantuml-check.yml`).

**Как работает:**
При пуше в PR GitHub скачивает PlantUML и прогоняет `-checkonly` по всем `.puml` файлам.
- Если синтаксис ок - чек зеленый, можно мержить.
- Если где-то опечатка или битый include - чек падает, и GitHub просто не даст смержить PR, пока не пофиксим.

### 3) Локальная проверка через Makefile

В корне проекта находится `Makefile` с таргетами для проверки и рендеринга диаграмм.

Проверка синтаксиса всех `.puml` файлов:

```bash
make check-diagrams
